1. La Propiedad `display` y el Flujo Normal Base Estructural

La propiedad display determina cómo se comporta visualmente una caja respecto a sus vecinos y qué capacidades de dimensionamiento posee:

Valor de Display Comportamiento en Flujo ¿Admite `width` y `height`? Etiquetas Habituales
block Ocupa el 100% del ancho disponible; provoca salto de línea antes y después. SÍ <div>, <p>, <h1>-<h6>, <section>
inline Fluye en la misma línea como texto; solo ocupa el ancho indispensable. NO (ignora width/height) <span>, <a>, <strong>, <em>
inline-block Fluye en la misma línea sin saltos, pero respeta dimensiones de caja completas. SÍ <button>, <input>, <img>
none Elimina el elemento del árbol de renderizado (no ocupa espacio en pantalla). No aplica Menús desplegables ocultos, modales cerrados
flex Activa el contexto de maquetación unidimensional (1D: fila o columna). SÍ Navbars, barras laterales, tarjetas
grid Activa el contexto de maquetación bidimensional (2D: filas y columnas simultáneas). SÍ Galerías, plantillas de página completas

2. Flexbox: Maquetación Unidimensional (1D) Animado con FLIP

💡 ¿Cómo funciona Flexbox?
• Opera sobre dos ejes: el Eje Principal (Main Axis) definido por flex-direction, y el Eje Secundario (Cross Axis) perpendicular a él.
• justify-content alinea sobre el Eje Principal; align-items alinea sobre el Eje Secundario.
• ¡Prueba los selectores inferiores! Observa la animación cinemática fluida y la flecha indicadora de dirección.
➡️ Eje Principal: X Horizontal (Izquierda ➔ Derecha) Eje Secundario: Perpendicular

Propiedades de los Hijos Flexibles (*Flex Items*)

      

        

          flex: 1 (Atajo grow + shrink + basis)
          
Permite que una columna crezca proporcionalmente para rellenar todo el espacio restante disponible.

        

        

          align-self
          
Sobrescribe la alineación del padre align-items únicamente para ese hijo en concreto.

        

        

          order
          
Modifica el orden de renderizado visual sin alterar la secuencia en el archivo HTML.

        

      

    


    
    

      

        3. CSS Grid: Maquetación Bidimensional (2D)
        Potencia Total
      


      

        💡 ¿Cuándo usar Grid en vez de Flexbox?
        Usa Flexbox cuando necesites alinear elementos en una sola dimensión (una fila o una columna). 
        Usa CSS Grid cuando necesites gobernar filas y columnas a la vez (rejillas, galerías, layouts de página completos con áreas nombradas).

        5. La Propiedad `overflow` y el Control de Desbordamientos
        Buenas Prácticas
      


      

        Determina qué hace el navegador cuando el contenido de un elemento excede las dimensiones físicas de su caja:
      


      

        

          overflow: hidden
          
Recorta cualquier elemento que sobresalga. Crucial para respetar esquinas redondeadas (border-radius) en tarjetas con imágenes o cabeceras hijas.

        


        

          overflow: auto
          
Muestra barras de scroll únicamente si el contenido lo requiere (estándar para tablas responsive anchas).

        


        

          Truncado en una línea con elipsis
          
Corta un texto demasiado largo añadiendo tres puntos (...) elegantes al final.

        

      


      
/* Truncado tipográfico estándar de la industria */
.texto-truncado-elegante {
  white-space: nowrap;        /* Impide que el texto salte de línea */
  overflow: hidden;           /* Oculta lo que se salga */
  text-overflow: ellipsis;    /* Añade los tres puntos (...) */
}

        7. La Guía Definitiva de Centrado en CSS
        Los 4 Métodos
      


      

        Centrar elementos en CSS ha sido históricamente uno de los desafíos más comentados del desarrollo web. Hoy en día disponemos de técnicas modernas extremadamente potentes y concisas. Conoce las 4 soluciones fundamentales y pruébalas en directo:

📊 Tabla Comparativa de Técnicas de Centrado

      

        

          
            

              Método
              Sintaxis Clave
              Ejes que Centra
              ¿Requiere Ancho Fijo?
              Caso de Uso Recomendado
            

          
          
            

              1. Flexbox
              display: flex; justify-content: center; align-items: center;
              Ambos (Horizontal y Vertical)
              No (Adaptable al contenido)
              Estándar universal para componentes, botones, barras de navegación y tarjetas.
            

            

              2. CSS Grid
              display: grid; place-items: center;
              Ambos (Horizontal y Vertical)
              No (Adaptable)
              Centrado rápido en solo 2 líneas de código (loaders, héroes y pantallas de acceso).
            

            

              3. Margen Auto
              width: 150px; margin: 0 auto;
              Solo Horizontal (X)
              Sí (Obligatorio en bloque)
              Contenedores estructurales de página centrados (ej. .container principal).
            

            

              4. Absolute + Transform
              position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);
              Ambos (Horizontal y Vertical)
              No (Usa su propio 50%)
              Ventanas modales emergentes (popups), tooltips flotantes o insignias superpuestas.
