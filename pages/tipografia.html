1. Propiedades Tipográficas Fundamentales Legibilidad & Jerarquía

La tipografía transmite la voz del diseño y estructura el orden de lectura. A diferencia de las propiedades de caja, las propiedades de texto se transmiten por herencia a todos los descendientes:

font-family

Define la familia tipográfica y la lista de fuentes alternativas de reserva (*font stack*). Siempre debe concluir con una categoría genérica (ej. sans-serif).

font-size

Tamaño de la fuente. Preferir unidades relativas como rem sobre px para garantizar accesibilidad ante el zoom del navegador.

font-weight

Grosor del trazo: de 100 (Ultra ligero) a 900 (Ultra negrita). Los valores más utilizados son 400 (normal) y 700 (bold).

line-height

Interlineado o altura de línea. La recomendación docente es usar multiplicadores sin unidad (ej. 1.5 o 1.6) para una lectura cómoda.

text-align

Alineación horizontal del texto dentro de su bloque contenedor: left, center, right o justify.

text-decoration

Líneas decorativas: none (quitar subrayado a enlaces), underline, line-through (tachado) o wavy (ondulado).

        3. Tipografía Fluida con la Función `clamp()`
        Técnica Avanzada
      


      

        La función clamp(mínimo, valor_preferido, máximo) permite crear textos que crecen y se encogen de manera fluida y suave en función del ancho de la pantalla sin necesidad de redactar docenas de media queries:
      


      

        
Estructura de clamp():

        

          font-size: clamp(1.2rem, 3vw, 2.5rem);

          • 1.2rem: Tamaño mínimo garantizado (para pantallas móviles pequeñas).

          • 3vw: Tamaño fluido preferido (equivale al 3% del ancho de la ventana).

          • 2.5rem: Tamaño máximo que nunca sobrepasará en pantallas ultra anchas.
        

      


      
/* Título responsive profesional sin una sola Media Query */
h1.titulo-hero {
  font-size: clamp(1.8rem, 4vw, 3.5rem);
  line-height: 1.15;
  font-weight: 800;
}

    


    
    

      

        4. Comparador de Unidades de Medida: px vs rem vs em vs %
        Accesibilidad y Escala
      


      

        Elegir las unidades tipográficas adecuadas es la base de un diseño web accesible, adaptable y mantenible. En la industria profesional, el debate central gira en torno a cómo reacciona cada unidad ante las preferencias del usuario:
      


      

        📏 Resumen de Unidades de Medida en CSS:

        • px (Píxeles absolutos): Tamaño estático e inflexible. ❌ Mala práctica para tipografía porque ignora las preferencias de zoom o accesibilidad del usuario en su navegador.

        • rem (Root EM): Relativo directamente al tamaño de fuente raíz del elemento <html> (por defecto 16px). ✅ Estándar moderno por ser predecible, escalable y 100% accesible.

        • em: Relativo al tamaño de fuente del padre directo. Muy potente para paddings proporcionales en botones, pero ⚠️ altamente peligroso en tipografías anidadas debido a su efecto bola de nieve / multiplicación exponencial.

        • %: Porcentual relativo al valor heredado del contenedor padre (ej. font-size: 150%; equivale a 1.5em).
      


      
      

        

          ⚙️ Simular Tamaño de Fuente Raíz (<html>):
          

            Modifica la preferencia de accesibilidad del usuario para ver cómo recalculan rem y em:
          

        

        

          
          
          
          
        

      


      
      

        

          

            ✅ Unidad rem (Accesible y Fluida)
            Recomendada
          

          

            font-size: 1.5rem; — Se recalcula dinámicamente multiplicando 1.5 × 16px.
          

          

            

              1.5rem = 24.0px
            

            Crece proporcionalmente si el usuario amplía la fuente del navegador.
          

        


        

          

            ❌ Unidad px (Rígida e Inaccesible)
            No Recomendada
          

          

            font-size: 24px; — Medida física estática grabada en piedra.
          

          

            

              24px (fijo, ignora accesibilidad)
            

            Permanece congelado en 24px aunque el usuario necesite fuentes más grandes.
          

        

      


      
      

        ⚠️ El Peligro del Efecto Multiplicador en Cascada de `em`
      

      

        Observa qué ocurre cuando anidamos 3 niveles de elementos y a cada uno le asignamos font-size: 1.25em vs font-size: 1.25rem:
      


      

        
        

          

            💥 Con `em`: Multiplicación Exponencial
          

          

            Cada hijo hereda y multiplica el tamaño de su padre directo:
          


          

            Nivel 1 (Padre): 1.25em ➔ 20.0px
            

              Nivel 2 (Hijo): 1.25em ➔ 25.0px
              

                Nivel 3 (Nieto): 1.25em ➔ 31.3px
              

            

          

        


        
        

          

            🛡️ Con `rem`: Estabilidad y Previsibilidad
          

          

            Todos los niveles toman como referencia únicamente la raíz <html>:
          


          

            Nivel 1 (Padre): 1.25rem ➔ 20.0px
            

              Nivel 2 (Hijo): 1.25rem ➔ 20.0px
              

                Nivel 3 (Nieto): 1.25rem ➔ 20.0px
              

            

          

        

      


      
/* Regla de Oro Front-End para Unidades */
html {
  font-size: 100%; /* Respeta el tamaño del navegador del usuario (16px base) */
}

body {
  font-size: 1rem; /* 16px */
}

h1 { font-size: 2.25rem; } /* 36px predecible en cualquier nivel */
p  { font-size: 1rem; }    /* 16px accesible */

.boton {
  padding: 0.5em 1em; /* ¡em aquí es perfecto! El padding crece si cambia la fuente del botón */
}
