1. El Árbol de Contenedores: Abuelo ➔ Padre ➔ Hijo ➔ Nieto

Cada <div> interior vive contenido dentro del espacio que le deja su elemento padre.

<!-- Estructura HTML Anidada --> <div class="abuelo"> <div class="padre"> <div class="hijo"> <div class="nieto">Texto más profundo</div> </div> </div> </div> /* CSS: Herencia */ .abuelo { color: #0d477a; /* SÍ se hereda por todos */ font-family: sans; /* SÍ se hereda */ padding: 20px; /* NO se hereda: solo para el abuelo */ border: 3px solid; /* NO se hereda */ }

2. Combinadores: Hijo Directo (>) vs Descendiente (Espacio)

Una pregunta clásica de examen es saber a qué elementos afecta exactamente cada selector.

/* 1. Selector descendiente (espacio): Afecta a TODOS los párrafos dentro del padre, sin importar cuántos niveles de anidamiento haya */ .padre p { color: blue; } /* 2. Selector hijo directo (>): Afecta ÚNICAMENTE a los hijos de primer nivel. NO afectará a párrafos que estén dentro de otros divs */ .padre > p { font-weight: bold; } /* 3. Hermano adyacente (+): Selecciona el primer elemento que va INMEDIATAMENTE después */ h3 + p { margin-top: 0; }

• Hijo directo (.padre > p):

Hereda estilos inmediatos sin penetrar en contenedores hijos.

• Descendiente (.padre p):

Penetra en cualquier profundidad del árbol DOM.

3. Posicionamiento Anidado: Padre relative + Hijo absolute

Para ubicar un botón flotante, una insignia o un avatar sobre una tarjeta, el padre DEBE tener position: relative para servir de anclaje.

/* 1. El padre actúa como marco de referencia */ .tarjeta-padre { position: relative; /* ¡IMPRESCINDIBLE! */ padding: 25px; background: white; border-radius: 10px; } /* 2. El hijo se fija a las esquinas del padre */ .badge-flotante { position: absolute; top: 10px; /* A 10px del techo del padre */ right: 10px; /* A 10px de la derecha del padre */ background: red; color: white; }
