1. Columnas Iguales: repeat(3, 1fr)

Divide el ancho total en 3 partes exactamente proporcionales sin calcular porcentajes con decimales.

/* CSS */ .contenedor { display: grid; grid-template-columns: repeat(3, 1fr); /* 3 columnas de 1 fracción */ gap: 10px; /* Hueco entre filas y columnas */ }

2. Responsive Mágico: repeat(auto-fit, minmax(130px, 1fr))

Genera tantas columnas como quepan. Si reduces la ventana, las tarjetas saltan solas de fila sin escribir ninguna `@media` query.

/* CSS */ .contenedor { display: grid; grid-template-columns: repeat(auto-fit, minmax(130px, 1fr)); gap: 10px; }

3. Estructura de Página: grid-template-areas

Permite dibujar el mapa visual de la web con palabras sencillas (header, nav, main, footer).

/* CSS */ .layout { display: grid; grid-template-columns: 140px 1fr; grid-template-areas: "header header" "nav main" "footer footer"; gap: 8px; } .header { grid-area: header; } .nav { grid-area: nav; } .main { grid-area: main; } .footer { grid-area: footer; }
