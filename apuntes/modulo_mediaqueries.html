1. Punto de Ruptura (*Breakpoint*): @media (max-width: 700px)

Cuando el ancho de la pantalla sea menor o igual a 700px, la maqueta pasa de fila horizontal a columna vertical apilada.

/* 1. Estilos base (Escritorio) */ .contenedor { display: flex; gap: 10px; } .lateral { flex: 1; } .principal { flex: 2; } /* 2. Regla Media Query (Móvil ≤ 700px) */ @media (max-width: 700px) { .contenedor { flex-direction: column; /* Apilamiento vertical */ } }
Lateral (flex: 1)
Principal (flex: 2)
