📱 Ejercicio 1.1: Calculadora Rotatoria con CSS Grid

Abrir Calculadora Interactiva ↗

Explicación: Con grid-template-columns: repeat(4, 1fr) se alinean los botones en 4 columnas. El botón = se expande con grid-column: span 2. 

/* CSS GRID */
.calculadora-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 12px;
}
.btn-igual { grid-column: span 2; }
@media (orientation: landscape) and (min-width: 650px) {
  .calculadora-card { display: grid; grid-template-columns: 240px 1fr; }
}

🎵 Ejercicio 1.2: Reproductor de Música Rotatorio con Flexbox

Abrir Reproductor Interactivo ↗

Explicación: División al 50%-50% en modo horizontal mediante flex-direction: row; y flex: 1; para carátula y controles. 

/* FLEXBOX 50/50 */
.reproductor-card { display: flex; flex-direction: column; gap: 20px; }
.barra-tiempo-progreso { width: 25%; }
@media (orientation: landscape) and (min-width: 650px) {
  .reproductor-card { flex-direction: row; }
  .seccion-disco, .seccion-controles { flex: 1; }
}
