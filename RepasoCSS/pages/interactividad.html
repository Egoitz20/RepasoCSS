1. Estados Dinámicos de Interacción Feedback de Usuario

Las pseudoclases de acción permiten informar visualmente al usuario de que la interfaz responde a sus acciones:

Pseudoclase Disparador Efecto Visual Recomendado
:hover El cursor del ratón entra en el área del elemento. Leve cambio de color de fondo, elevación con sombra o escala suave.
:focus / :focus-visible El elemento recibe foco mediante teclado (Tab) o clic. Anillo de contorno contrastado (box-shadow: 0 0 0 3px ...).
:active El usuario presiona y mantiene pulsado el botón del ratón o pantalla táctil. Sensación de pulsación física: reducción ligera de escala o traslación hacia abajo.
:visited El enlace apunta a una URL que ya figura en el historial del navegador. Tono de color más apagado para evitar clics redundantes.

2. Transiciones en CSS (`transition`) Suavidad Cinemática

Una transición interpola gradualmente el cambio entre dos valores CSS a lo largo del tiempo:

Sintaxis Abreviada:

transition: [propiedad] [duración] [función-aceleración] [retardo];

Ejemplo: transition: transform 0.3s cubic-bezier(0.25, 1, 0.5, 1), box-shadow 0.3s ease;

💡 Consejo de Rendimiento Front-End Senior: Evita usar transition: all en elementos complejos. Anima preferentemente propiedades que aprovechan la aceleración por GPU (transform y opacity) sin forzar repintados continuos del DOM (*reflow*).

/* Definición de la animación de pulso de Ki */
@keyframes pulsoKi {
  0% {
    box-shadow: 0 0 0 0 rgba(245, 158, 11, 0.7);
  }
  70% {
    box-shadow: 0 0 0 20px rgba(245, 158, 11, 0);
  }
  100% {
    box-shadow: 0 0 0 0 rgba(245, 158, 11, 0);
  }
}

.guerrero-aura {
  animation: pulsoKi 2s infinite ease-in-out;
}
