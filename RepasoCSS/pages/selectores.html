1. Selectores Básicos Fundamentos

Los selectores básicos son las herramientas primordiales para seleccionar elementos HTML en función de su nombre de etiqueta, clase o identificador único:

Selector Sintaxis Especificidad Cuándo Utilizarlo
Universal * (0, 0, 0) Para el reset global de márgenes, paddings y box-sizing: border-box.
Tipo / Etiqueta h1, p, button (0, 0, 1) Estilos base semánticos compartidos por todas las instancias de un elemento.
Clase .tarjeta, .chip-item (0, 1, 0) El estándar de oro en CSS moderno. Reutilizable, modular y escalable.
Identificador (ID) #header-principal (1, 0, 0) Elementos estrictamente únicos en toda la página. Evitar en estilos comunes debido a su alta especificidad destructiva. 
/* Ejemplo de buenas prácticas con selectores básicos */
* {
  box-sizing: border-box;
}

h2 {
  color: var(--color-primario);
}

.tarjeta-entrenamiento {
  background: white;
  border-radius: var(--radio-tarjeta);
  border: 1px solid var(--color-borde);
}

2. Selectores Combinados (Relaciones Padre-Hijo) Estructura DOM

💡 Clave didáctica para maquetación: Comprender la diferencia exacta entre un descendiente (cualquier nivel) y un hijo directo (primer nivel) es lo que distingue a un desarrollador junior de uno senior.
Combinador Símbolo Ejemplo Alcance de Selección
Descendiente (Espacio) .padre p Cualquier <p> que esté dentro de .padre (hijos, nietos, bisnietos...).
Hijo Directo > .padre > p Únicamente los <p> de primer nivel que son hijos inmediatos. Ignora nietos.
Hermano Adyacente + h2 + p El primer hermano <p> que viene inmediatamente después del <h2>.
Hermanos Generales ~ h2 ~ p Todos los párrafos hermanos que comparten el mismo padre y aparecen después del <h2>.

5. Calculadora y Comparador Visual de Especificidad Batalla de Reglas

La Especificidad es el algoritmo que emplea el motor de renderizado del navegador para decidir qué declaración CSS gana cuando dos o más reglas compiten por dar estilo al mismo elemento HTML.

⚖️ Las 4 Columnas de Puntuación [Inline, ID, Clase, Elemento]:
• [a] Estilo en línea (Inline): <div style="..."> otorga 1-0-0-0. Máxima prioridad sobre selectores normales.
• [b] Identificadores únicos (ID): Cada #id suma 0-1-0-0. ¡Un solo ID vence a 10.000 clases acumuladas!
• [c] Clases, pseudoclases y atributos: Cada .clase, :hover o [type] suma 0-0-1-0.
• [d] Etiquetas y pseudoelementos: Cada div, p o ::before suma 0-0-0-1.
• Regla de Desempate: Si la tupla [a, b, c, d] es idéntica, prevalece La Cascada (orden en el código).
