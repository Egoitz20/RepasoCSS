🏛️ Los 3 Pilares del Motor de CSS Concepto Clave

Antes de profundizar en propiedades individuales, todo desarrollador Front-End senior debe dominar las tres reglas fundamentales que rigen cómo el navegador interpreta las hojas de estilo:

1. La Cascada (Cascade)

Cuando existen dos o más reglas con la misma especificidad que apuntan al mismo elemento, el navegador aplica la última declarada en el código (orden de aparición).

2. La Especificidad

El sistema de puntuación que decide qué selector tiene mayor peso: !important > Estilos en línea > ID (#id) > Clase/Pseudoclase (.clase) > Etiqueta (div).

3. La Herencia (Inheritance)

Las propiedades tipográficas (color, font-family, etc.) se transmiten automáticamente de padres a hijos. Las propiedades de caja (margin, padding, border) nunca se heredan. 

/* Reset Universal Obligatorio en Todo Proyecto Moderno */
*, *::before, *::after {
  box-sizing: border-box; /* Garantiza medidas predecibles sin desbordamientos */
  margin: 0;
  padding: 0;
}
