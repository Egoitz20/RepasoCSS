1. Calculadora Rotatoria (CSS Grid)

CSS Grid (2D) + Media Query
💡 ¿Por qué se utiliza CSS Grid en este ejercicio? (Explicación para examen):
  • Cuadrícula bidimensional perfecta: La botonera de una calculadora requiere alinear filas y columnas de manera uniforme sin desajustes. Con grid-template-columns: repeat(4, 1fr) creamos 4 columnas idénticas en una sola línea.
  • Expansión de celdas con grid-column: span 2: El botón del igual (=) ocupa dos columnas completas sin necesidad de usar anchos fijos en píxeles.
  • Modo apaisado (landscape) adaptativo: Con @media (orientation: landscape) and (min-width: 650px) reordenamos el contenedor en dos columnas principales (pantalla LCD a la izquierda de 240px y botonera a la derecha con 1fr), aprovechando todo el ancho de la pantalla tal y como exige el temario.
/* 1. Contenedor de botones: Rejilla de 4 columnas iguales */
.calculadora-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr); /* 4 columnas que se reparten 1 fracción equitativa */
  gap: 12px;                            /* Separación uniforme entre botones */
}

/* 2. Botón del igual expandido horizontalmente */
.btn-igual {
  grid-column: span 2;                  /* Ocupa 2 columnas de la cuadrícula */
  background-color: #10b981;            /* Color verde para diferenciarlo */
}

/* 3. Reorganización en modo apaisado / landscape (Rotación) */
@media (orientation: landscape) and (min-width: 650px) {
  .calculadora-card {
    max-width: 680px;
    display: grid;
    grid-template-columns: 240px 1fr;   /* Pantalla LCD a la izq, botones a la derecha */
    gap: 20px;
  }
}
<!-- Estructura HTML de la Calculadora con CSS Grid -->
<main class="calculadora-card">
  <!-- Pantalla LCD -->
  <div class="calculadora-display" id="display">0</div>

  <!-- Botonera en Cuadrícula -->
  <div class="calculadora-grid">
    <button class="btn-calc btn-borrar">C</button>
    <button class="btn-calc btn-operador">/</button>
    <button class="btn-calc btn-operador">*</button>
    <button class="btn-calc btn-operador">-</button>

    <button class="btn-calc">7</button>
    <button class="btn-calc">8</button>
    <button class="btn-calc">9</button>
    <button class="btn-calc btn-operador">+</button>

    <!-- Botón = expandido a 2 columnas -->
    <button class="btn-calc btn-igual">=</button>
  </div>
</main>

2. Reproductor de Música Rotatorio (Flexbox 50/50)

Flexbox (1D) + Media Queries
💡 ¿Por qué se utiliza Flexbox en este ejercicio? (Explicación para examen):
  • Flujo Unidimensional en Columna: En modo vertical (portrait), todos los componentes se apilan de forma limpia con display: flex; flex-direction: column; gap: 20px;.
  • Alineación central de controles: Los botones de reproducción (anterior, play/pause, siguiente) se centran fácilmente en el eje horizontal usando display: flex; justify-content: center; align-items: center; gap: 25px;.
  • División al 50%-50% en horizontal (Landscape): Al rotar o detectar pantallas anchas, el contenedor pasa a flex-direction: row; y tanto la sección del disco como la de controles toman flex: 1;, repartiéndose exactamente la mitad de la pantalla cada una como indica la sección 1.2 del temario.
  • Barras de progreso proporcionales: El carril gris tiene width: 100%; border-radius: 10px; overflow: hidden; y el relleno interno se define con width: 25%; (tiempo) y width: 70%; (volumen).
/* 1. Contenedor vertical por defecto */
.reproductor-card {
  display: flex;
  flex-direction: column; /* Apilamiento vertical */
  gap: 20px;
  max-width: 380px;
}

/* 2. Barra de tiempo fija al 25% requerida por la teoría */
.barra-tiempo-progreso {
  width: 25%;             /* Marcada al 25% según especificación del examen */
  height: 100%;
  background-color: #38bdf8;
  border-radius: 10px;
}

/* 3. Botones centrados con Flexbox */
.botones-reproduccion {
  display: flex;
  justify-content: center;/* Centrados horizontalmente */
  align-items: center;    /* Centrados verticalmente */
  gap: 25px;              /* Separación uniforme */
}

/* 4. División al 50%-50% en modo apaisado / landscape */
@media (orientation: landscape) and (min-width: 650px) {
  .reproductor-card {
    max-width: 750px;
    flex-direction: row;  /* Pasa a dos columnas horizontales */
    gap: 30px;
  }
  .seccion-disco, .seccion-controles {
    flex: 1;              /* Exactamente 50% para el disco y 50% para controles */
  }
}
<!-- Estructura HTML del Reproductor de Música -->
<main class="reproductor-card">
  <!-- Lado 1: Disco / Carátula -->
  <section class="seccion-disco">
    <div class="disco-img"><div class="vinilo-centro"></div></div>
  </section>

  <!-- Lado 2: Controles y Barras -->
  <section class="seccion-controles">
    <h2>Cha-La Head-Cha-La</h2>
    <h3>Dragon Ball Z OST</h3>

    <!-- Barra al 25% -->
    <div class="barra-tiempo-pista">
      <div class="barra-tiempo-progreso"></div>
    </div>

    <!-- Botones Flexbox -->
    <div class="botones-reproduccion">
      <button class="btn-ctrl">⏮</button>
      <button class="btn-ctrl btn-play-pause">▶</button>
      <button class="btn-ctrl">⏭</button>
    </div>
  </section>
</main>

3. Barra de Navegación Responsive & Catálogo Grid

Flexbox + CSS Grid Auto-fit
💡 Técnicas clave explicadas:
  • justify-content: space-between; separa el logotipo a la izquierda y el menú a la derecha automáticamente.
  • grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); genera tantas tarjetas de mínimo 240px como quepan en la pantalla sin necesidad de escribir media queries.
/* Navbar con Flexbox */
.header-nav {
  display: flex;
  justify-content: space-between; /* Logo a la izq, enlaces a la der */
  align-items: center;
  padding: 16px 30px;
}

/* Catálogo de tarjetas auto-adaptable con Grid */
.catalogo-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); /* Auto-responsive */
  gap: 25px;
}
<!-- Estructura HTML -->
<header class="header-nav">
  <div class="logo">⚡ ACADEMIA</div>
  <ul class="nav-enlaces">
    <li><a href="#">Inicio</a></li>
    <li><a href="#">Técnicas</a></li>
  </ul>
</header>

<div class="catalogo-grid">
  <article class="tarjeta-curso">...</article>
</div>
