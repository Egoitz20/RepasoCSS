1. Reparto a Extremos: justify-content: space-between

Esencial para barras de navegación (logo a un lado, menú al otro) o cabeceras de tarjetas con insignias.

/* CSS */ .contenedor { display: flex; justify-content: space-between; /* Primer hijo al inicio, último al final */ align-items: center; }

2. Centrado Absoluto: center en ambos ejes

Pregunta fija: cómo centrar horizontal y verticalmente sin usar márgenes fijos ni hacks.

/* CSS */ .contenedor { display: flex; justify-content: center; /* Eje principal (horizontal) */ align-items: center; /* Eje secundario (vertical) */ min-height: 120px; }
🎯 ¡Centrado Total!

3. Flujo Vertical: flex-direction: column

Lo que activa la media query cuando se pasa de pantalla de ordenador a móvil.

/* CSS */ .contenedor { display: flex; flex-direction: column; /* El eje principal ahora es vertical */ gap: 10px; /* Espacio entre filas */ }

4. Salto Dinámico de Línea: flex-wrap: wrap

Utilizado para las etiquetas o chips (Kamehameha, Genkidama, Kaio-ken...) para que no se salgan de pantalla.

/* CSS */ .contenedor { display: flex; flex-wrap: wrap; /* Si no caben en una fila, pasan a la siguiente */ gap: 10px; }
