📦 Guía de Estudio Rápida: Margin vs Padding

Compara el código con el comportamiento visual del espacio interior y exterior.

⬅ Volver al Laboratorio

1. Padding (Relleno Interior): Espacio dentro del borde

El color de fondo se extiende por toda la zona del padding. Amplía la superficie de pulsación en botones.

/* CSS */ .boton-o-caja { background-color: #c8e6c9; border: 3px solid #2e7d32; padding: 25px; /* 25px de espacio hacia ADENTRO */ }
Texto con 25px de Padding
(El fondo verde llena todo el espacio interno)

2. Margin (Margen Exterior): Separación entre elementos

El margen es 100% transparente y empuja a las cajas adyacentes para que no se peguen.

/* CSS */ .caja-superior { margin-bottom: 25px; /* Separa 25px de la caja inferior */ } .caja-inferior { /* El espacio intermedio es transparente */ }
Caja Superior (margin-bottom: 25px)
Caja Inferior (Empujada hacia abajo)
