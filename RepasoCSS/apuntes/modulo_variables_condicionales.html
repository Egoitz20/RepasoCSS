🎨 Variables CSS y "Condicionales" (If / Else)

Descubre cómo cambiar paletas completas con :root y cómo usar :has(), :not() y @media como condicionales lógicos.

1. Variables CSS (Custom Properties) y Conmutación de Temas

Pulsa los botones para ver cómo la caja inferior cambia instantáneamente de colores sin reescribir propiedades individuales, solo cambiando el valor de las variables.

/* 1. Definición en :root */ :root { --color-primario: #0d477a; --color-fondo: #ffffff; --color-texto: #1e293b; } /* 2. Reasignación condicional en tema oscuro */ .tema-oscuro { --color-primario: #38bdf8; --color-fondo: #1e293b; --color-texto: #f8fafc; } /* 3. Los elementos consumen la variable */ .tarjeta { background: var(--color-fondo); color: var(--color-texto); border: 2px solid var(--color-primario); }

Tarjeta Dinámica con Variables

El fondo, el borde y el texto de esta caja responden directamente a var(--color-tema-...).

2. El Condicional "If" de CSS: :has()

:has() permite evaluar una condición: "Si este contenedor contiene a un elemento con estado X, cámbiale el diseño". ¡Marca el checkbox de abajo para ver la condición cumplirse en vivo!

/* CONDICIONAL IF: "Si .tarjeta contiene un input marcado (:checked)..." */ .tarjeta:has(input:checked) { background-color: #dcfce7; /* Fondo verde */ border-color: #16a34a; /* Borde verde */ box-shadow: 0 4px 12px rgba(22, 163, 74, 0.2); } .tarjeta:has(input:checked) h4 { color: #15803d; }

Tarea de Entrenamiento

CSS puro detecta si el checkbox está marcado usando :has(input:checked).

3. La Negación Lógica: :not()

Aplica un estilo a todos los elementos que no cumplan una condición (ej: separar todos los elementos excepto el último).

/* Aplica borde inferior a todos MENOS al último */ li:not(:last-child) { border-bottom: 1px dashed #cbd5e1; }
  • Primer ítem (con borde inferior)
  • Segundo ítem (con borde inferior)
  • Último ítem (:last-child no lleva borde)
