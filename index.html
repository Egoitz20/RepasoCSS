📦 1. El Modelo de Caja (Box Model)
Ver Código Aislado ↗ Fijo en examen

💡 Regla de oro para el examen:
• Padding (relleno): Espacio interior (entre el texto y el borde). Lleva el color de fondo del elemento y amplía la zona de clic.
• Margin (margen): Espacio exterior (entre el borde del elemento y sus vecinos). Es 100% transparente.
• box-sizing: border-box: Obligatorio en proyectos reales para que el padding y el border no sumen anchura extra y rompan la maquetación.
Ancho total = 200px (fijo gracias a border-box)
CONTENIDO
(width: 160px) 
/* Reset universal indispensable en todo examen y proyecto */
*, *::before, *::after {
  box-sizing: border-box; /* El width especificado incluye padding y border */
  margin: 0;
  padding: 0;
}

🌳 2. Jerarquía DOM y Anidamiento (Div dentro de Div)
Ver Código Aislado ↗ Crucial

🔍 Cómo funcionan las cajas anidadas:
• Herencia: Las propiedades de texto (color, font-family, font-size) se transmiten automáticamente a todos los hijos y nietos interiores.
• NO se heredan: margin, padding, border, width y background solo pertenecen al contenedor que los declara.
• Flexbox/Grid: Sólo aplican a los hijos directos (los nietos no se vuelven flexibles a menos que su propio padre sea flex).
• Patrón Padre Relative + Hijo Absolute: Para fijar una insignia en la esquina de una tarjeta, el padre debe ser position: relative.
DIV ABUELO (.abuelo - color: azul; font-family)

Contenedor raíz exterior. Sus propiedades de texto bañan a todos los elementos interiores.

DIV PADRE (.padre - position: relative;)

Hijo directo del abuelo. Sirve de marco de anclaje.

DIV HIJO (.hijo - flex hijo directo)

Elemento intermedio contenido dentro del padre.

DIV NIETO (.nieto - contenido interior profundo) 
/* Combinadores clave entre padres e hijos */
.padre p { color: blue; }         /* Descendiente (espacio): Hijos, nietos, etc. */
.padre > p { font-weight: bold; } /* Hijo directo (>): SOLO primer nivel */
h2 + p { margin-top: 0; }         /* Hermano adyacente (+): Inmediatamente después */

🎨 3. Variables CSS (`:root`) y Sistema de Temas
Ver Código Aislado ↗ Moderno

💡 ¿Por qué usar Variables CSS?
Permiten centralizar colores, medidas y fuentes en un único lugar. Cambiando una sola variable, toda la interfaz se actualiza al instante.
¡Prueba los botones para conmutar el tema visual de esta tarjeta!

Demostración Dinámica de Variables

Esta tarjeta utiliza var(--color-primario), var(--color-tarjeta-bg) y var(--color-texto). Al pulsar los botones de arriba, solo cambiamos las variables y el diseño se transforma. 

/* Declaración global en :root y reasignación de tema */
:root {
  --color-primario: #0d477a; /* Variable global */
}
body.modo-oscuro {
  --color-primario: #38bdf8; /* Reasignada para todo el tema oscuro */
}
.tarjeta {
  background: var(--color-primario);
}

🔀 4. Los "Condicionales" en CSS (If / Else)
Ver Código Aislado ↗ Muy preguntado

¿Cómo se hacen condicionales en CSS?
• @media: if (ancho <= 768px) { vertical; } else { horizontal; }
• :has(): El condicional de hijos: if (padre contiene hijo con estado X).
• :not(): La negación lógica: if NOT condition.
• @supports: if (navegador soporta display: grid).

🎯 Condicional :has() en Vivo

Haz clic en la casilla para activar la condición CSS: .caja:has(input:checked) 

/* Condicionales puros en CSS */
.tarjeta:has(input:checked) {
  background-color: #dcfce7;
  border-color: #16a34a;
}
li:not(:last-child) {
  border-bottom: 1px solid #cbd5e1;
}

📱 Ejercicio 1.1: Calculadora Rotatoria con CSS Grid

Abrir Calculadora Interactiva ↗

Explicación: Se utiliza display: grid; grid-template-columns: repeat(4, 1fr); para crear 4 columnas idénticas para la botonera. El botón de igual (=) se expande con grid-column: span 2. En modo apaisado (landscape), una Media Query reorganiza el display LCD a la izquierda y los botones a la derecha con grid-template-columns: 240px 1fr. 

/* CÓDIGO CLAVE DE LA CALCULADORA (CSS GRID) */
.calculadora-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr); /* 4 columnas exactamente iguales */
  gap: 12px;                            /* Separación entre botones */
}

.btn-igual {
  grid-column: span 2;                  /* El botón = ocupa 2 columnas */
  background-color: #10b981;
}

/* Rotación apaisada / landscape (según teoría) */
@media (orientation: landscape) and (min-width: 650px) {
  .calculadora-card {
    display: grid;
    grid-template-columns: 240px 1fr;   /* Pantalla 240px a la izq, botonera al resto */
  }
}

🎵 Ejercicio 1.2: Reproductor de Música Rotatorio con Flexbox

Abrir Reproductor Interactivo ↗

Explicación: Los controles principales se centran en fila con display: flex; justify-content: center; align-items: center; gap: 25px;. La barra de tiempo va fija al 25% y el volumen al 70%. Al rotar la pantalla, una Media Query activa flex-direction: row; y da flex: 1; al disco y flex: 1; a los controles para dividir la pantalla al 50%-50%. 

/* CÓDIGO CLAVE DEL REPRODUCTOR (FLEXBOX 50/50) */
.reproductor-card {
  display: flex;
  flex-direction: column; /* Modo vertical */
  gap: 20px;
}

.barra-tiempo-progreso {
  width: 25%;             /* Fijado al 25% por especificación del examen */
}

/* División al 50%-50% en modo apaisado / horizontal */
@media (orientation: landscape) and (min-width: 650px) {
  .reproductor-card {
    flex-direction: row;  /* Pasa a dos columnas */
  }
  .seccion-disco, .seccion-controles {
    flex: 1;              /* 50% para carátula y 50% para controles */
  }
}

⚡ 6. Flexbox Interactivo y Animado (1D - Unidimensional)
Ver Código Aislado ↗ Fundamental

🧭 Conceptos clave de Flexbox:
• flex-direction: Define el eje principal (row = horizontal; column = vertical).
• justify-content: Alinea a lo largo del eje principal.
• align-items: Alinea a lo largo del eje secundario/perpendicular.
• Animación Visible: Al cambiar cualquier opción, los bloques se desplazan con movimiento cinético y la flecha inferior indica la dirección del flujo.
➡️ Eje Principal: X Horizontal (Izquierda → Derecha) Eje Secundario: Perpendicular (Cross Axis)

          1. ¿Cómo funciona la herencia dentro de los bloques `div` anidados?
          ▼
        

        

          Respuesta modelo:
          
    
            
  • Propiedades que SÍ se heredan: Tipografías y texto (color, font-family, font-size, text-align). Pasan automáticamente a todos los hijos y nietos interiores.
    • 
            
  • Propiedades que NO se heredan: Modelo de caja (margin, padding, border), dimensiones (width, height), fondos y display (flex/grid). Solo se aplican al contenedor específico.
    • 
          

        

      


      

        

          2. ¿Cuáles son los condicionales ("if / else") que existen en CSS?
          ▼
        

        

          Respuesta modelo:
          
    
            
  • @media: Condicional de pantalla (ancho, orientación). Actúa como if (ancho <= 768px).
    • 
            
  • :has(): Condicional de hijos. Estiliza al padre si contiene a un determinado elemento (ej: div:has(input:checked)).
    • 
            
  • :not(): Condicional de negación lógica.
    • 
            
  • @supports: Condicional de compatibilidad de características del navegador.
    • 
          

        

      


      

        

          3. ¿Cuál es la diferencia entre margin y padding en CSS?
          ▼
        

        

          Respuesta modelo:
          
    
            
  • Padding (relleno): Espacio interior entre contenido y borde. Adopta el color de fondo y es clicable.
    • 
            
  • Margin (margen): Espacio exterior entre el borde y los vecinos. Es transparente y separa elementos.
